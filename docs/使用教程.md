# 海草跨境助手使用教程

## 1. 下载与安装

可任选一个下载渠道：

- [蓝奏云下载文件夹](https://wwamz.lanzouu.com/b01euscfwj)，输入提取码 **9ysu**。
- [GitHub Releases](https://github.com/xhcao8-spec/seagrass-assistant/releases/latest)，展开 **Assets**，下载 `SeagrassAssistant-Setup-版本号.exe`。

`Source code (zip)` 和 `Source code (tar.gz)` 是给开发者使用的源码，不是 Windows 安装包。普通用户只需下载 `.exe`。不同渠道的版本以实际上传的文件为准。

安装后启动“海草跨境助手”，在系统设置中配置自己的 DeepSeek API Key。

**由于时间有限，目前暂时只完善 WhatsApp，后续将逐步完善其他平台。** 其他平台入口仍在适配，不代表功能已经全部完成。

## 2. 获取自己的 DeepSeek API Key

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册或登录你自己的账号。
2. 进入 [API Keys 页面](https://platform.deepseek.com/api_keys)，创建一个 API Key。界面名称如有变化，以官方页面为准。
3. 复制新生成的完整 Key。它是访问你账户的凭证，不要发送给别人，不要截图公开，不要提交到代码仓库。
4. 如果没有可用 API 余额，请在 DeepSeek 官方平台查看充值和计费说明。聊天网页版与 API 的使用权益不要混淆，以 API 账户余额为准。

软件作者不代收 DeepSeek 费用，也不需要获取你的 Key。

## 3. 填入 Key 并测试

1. 在软件左侧进入“系统设置”。首次未配置 Key 时会自动打开这里。
2. 在“DeepSeek API”的“API Key”栏粘贴 Key。
3. 软件使用支持识图的 DeepSeek V4.1 Flash（接口名 `deepseek-flash`），不用自己填写模型。
4. 点击“保存 API 设置”，再点击“测试已保存的 Key”。测试连接读取模型列表，不发送你的聊天内容。
5. 成功后进入“余额”，点击“刷新余额”。这里显示 DeepSeek 官方返回的金额和币种。

软件不设置请求并发上限，没有并发设置或内部排队。DeepSeek 服务自身仍有接口限制。临时限流、网络错误、超时或暂时服务异常会自动重试最多 2 次（含首次最多 3 次），重试之间等待，避免连续冲击接口。余额不足、Key 无效、权限或参数错误不会自动重试，会直接提示处理。如果接口要求等待超过 10 秒，则停止本轮并提示稍后重试，不提前违反服务端的等待要求。

超时不一定意味着 DeepSeek 未处理请求，因此自动重试可能产生额外 API 用量，实际计费以官方为准。

保存成功后输入框会清空并显示“已保存”。这是为了避免 Key 长期显示在界面，不是保存失败。再次保存时，Key 留空表示继续使用原 Key。

点击“移除 Key”只移除本机保存的凭证，不会删除标签、话术或聊天账号。如果 Key 泄露，还需到 DeepSeek 开放平台撤销它；只从软件移除不等于官方撤销。

## 4. 打开聊天平台

1. 进入“应用中心”，优先选择目前重点完善的 WhatsApp 并创建窗口。
2. 为窗口取名。可直连，也可选择你自己的代理；代理信息仅保存在本机。
3. 在平台页面扫码或登录自己的账号，按平台要求完成验证。
4. 顶部标签可切换窗口，齿轮打开该窗口的翻译设置。

软件不能绕过 Facebook、Google 等平台的登录或安全验证。某个平台登录失败时，请先在受支持的浏览器或手机端确认账号是否正常。

## 5. 使用翻译

- 在窗口翻译设置中选择发送语言、客户消息语言、译文显示语言及是否自动翻译。
- 客户专属设置可沿用窗口默认，或针对当前客户单独设置。
- 自动翻译可能处理当前加载的多条消息，会产生 DeepSeek API 用量；不需要时关闭自动翻译。
- 手动“重新翻译”会重新请求 DeepSeek，不是重复展示旧缓存。
- 发送前请检查译文，尤其是金额、时间、姓名和承诺。

## 6. AI 建议回复

1. 打开目标聊天，点击输入框附近的 AI 按钮。
2. 可在“这次希望 AI 帮你完成什么”中填写目的，例如“回应他的旅行分享，不谈业务，语气像朋友”。
3. 选择快速回复或精聊回复，再选择 1—4 条建议。
4. 生成后核对原文、中文译文和上下文。点击“插入输入框”后仍可修改。
5. **软件不会自动发送 AI 草稿。** 最终发送由你决定。

AI 会参考已读取的当前对话，区分“我”和“对方”，但仍可能误解信息。它不知道未加载的历史，也不应替你编造事实、个人经历或承诺。

### 图片理解（WhatsApp）

打开当前聊天，滚动到最新消息并让图片加载完成，再点击生成。软件会将当前已加载消息中最近的最多 4 张可读取图片随文字发送给 DeepSeek，标注每张图片对应的消息顺序及发送方；仅图片、没有文字的消息也能参与回复。生成成功后会提示实际使用的图片数量。

这不是对整台电脑截屏，也不会读取其他聊天或扫描本地相册。头像、表情和引用缩略图会过滤；未加载、无法读取或视图中被裁切的跨域图片不会被猜测为已读。请勿提供无需发送给 AI 的隐私图片。图片仅在当前生成请求中临时使用，不写入聊天归档。识图会产生 DeepSeek API 用量。

切换对话后请在新的聊天中重新打开 AI 面板；软件会核对当前联系人，防止旧图片或旧建议误用于其他聊天。

## 7. 本地标签与快捷回复

聊天里的标记、标签、单独翻译设置和快捷话术/图片都保存在本机。更换电脑、重装系统、卸载或清理数据前请备份。

数据目录：`%APPDATA%/SeagrassStandalone`。退出软件后再备份整个目录；此目录含平台登录资料、标记和翻译缓存，不能公开分享。API Key 的加密绑定当前系统环境，换电脑应重新填写，不要尝试把密钥文件公开传递。

点击软件左下角“下载新版”，会自动复制提取码 **9ysu** 并打开固定蓝奏云文件夹，显示“提取码已复制”。在蓝奏云网页中粘贴密码即可；软件不会假装已替网页完成填写。查看版本号，下载新版安装包，关闭软件后手动安装。不会强制自动安装或突然重启。

作者上传新版后会出现在同一个文件夹中。文件夹链接不是安装包直链，不能用于静默下载更新。

也可以从官网进入 GitHub 下载，或直接打开 [GitHub Releases](https://github.com/xhcao8-spec/seagrass-assistant/releases/latest)。更新前保存草稿并退出软件，再运行新版安装包。

## 常见问题

- **未配置 Key**：在系统设置中填写并保存，再测试。
- **Key 无效**：检查是否复制完整、是否已撤销，必要时创建新 Key。
- **DeepSeek 余额不足**：到 DeepSeek 官方平台查看余额与充值说明。
- **查询余额失败**：不代表余额为零；检查网络或 Key 后刷新。
- **超时/限流**：软件会按上述规则自动重试，仍失败才提示手动重试。DeepSeek 自身的服务限制仍然适用。
- **软件关掉后设置丢失**：检查是否换了 Windows 用户、数据目录被清理或运行了另一个版本。
- **没有网络能用吗**：可以查看已保存的本地内容，但平台聊天、翻译、AI 和余额查询都需要联网。

参考：[DeepSeek 接口说明](https://api-docs.deepseek.com/)、[官方余额接口](https://api-docs.deepseek.com/zh-cn/api/get-user-balance/)。
