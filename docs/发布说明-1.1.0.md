# 海草跨境助手 v1.1.0

**用 DeepSeek AI 翻译聊天，让跨语言沟通更自然。**

由于时间有限，目前暂时只完善 WhatsApp，后续将逐步完善其他平台。

## 功能亮点

- **AI 消息翻译**：由 DeepSeek V4.1 Flash（`deepseek-flash`）提供收发翻译，支持自动、手动及重新翻译。
- **AI 建议回复**：参考当前对话和你的回复目的，提供快速/精聊两种模式，每次可生成 1—4 条带中文参考的草稿。
- **聊天图片理解**：结合 WhatsApp 当前聊天已加载的最多 4 张可读取图片生成回复建议。
- **多窗口沟通**：切换不同聊天窗口，独立设置翻译语言与网络代理。
- **聊天辅助**：本地聊天标签、专属翻译设置、快捷话术和图片分组。
- **自有 Key**：在系统设置填写自己的 DeepSeek API Key，直接查询官方余额；临时网络故障、超时或限流自动重试最多 2 次。

## 下载与开始使用

Windows 10 / 11 x64 用户请下载本页 Assets 中的 **`SeagrassAssistant-Setup-1.1.0.exe`**。`Source code` 压缩包是源码，不是安装程序。

[完整中文教程](https://github.com/xhcao8-spec/seagrass-assistant/blob/main/docs/使用教程.md) · [蓝奏云下载](https://wwamz.lanzouu.com/b01euscfwj)（提取码：9ysu） · [源码与功能介绍](https://github.com/xhcao8-spec/seagrass-assistant)

安装 → 系统设置填写 Key → 保存并测试 → 应用中心创建 WhatsApp 窗口 → 手机扫码 → 设置翻译语言。

软件免费开源，DeepSeek API 调用按官方规则计费。AI 处理所需文本和图片会发送给 DeepSeek；回复草稿不会自动发送，请核对后使用。
