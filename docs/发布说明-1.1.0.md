# 海草跨境助手 1.1.0

由于时间有限，目前暂时只完善 WhatsApp，后续将逐步完善其他平台。

## 本次内容

- 用户在本机填写自己的 DeepSeek API Key，直接调用官方 API。
- “余额”显示 DeepSeek 返回的实际金额，去掉套餐、充值订单和字符额度。
- 去掉团队、共享、客户档案与业务后端依赖，保留聊天标签与本地快捷回复。
- WhatsApp 翻译、AI 快速/精聊回复，支持选择 1—4 条备选草稿及填写回复目的。
- WhatsApp AI 建议可结合当前聊天已加载的最多 4 张可读取图片。
- 不设软件并发上限；临时限流、网络错误或超时自动重试最多 2 次，余额不足和 Key 无效停止并提示。
- 修复翻译失败结果被缓存，以及自动翻译内部串行排队的问题。
- 更新入口打开蓝奏云并复制提取码，不会强制安装或突然重启。

## 下载与使用

普通用户请下载本页 Assets 中的 `SeagrassAssistant-Setup-1.1.0.exe`，不要把 Source code 压缩包当成安装程序。

[完整中文教程](https://github.com/xhcao8-spec/seagrass-assistant/blob/main/docs/使用教程.md) · [蓝奏云备用下载](https://wwamz.lanzouu.com/b01euscfwj)（提取码：9ysu）

安装后进入系统设置，保存自己的 DeepSeek API Key，再到应用中心创建 WhatsApp 窗口并扫码登录。

## 注意

- 软件本身不出售套餐；DeepSeek API 调用可能产生费用，超时重试也可能产生额外用量。
- 翻译和 AI 所需文本、图片会发送给 DeepSeek。AI 草稿不会自动发送，请核对后使用。
- 新版与旧售卖版数据独立，首次使用可能需要重新扫码。请勿公开用户运行数据。
- 其他平台尚在完善；实际识图与回复质量取决于模型和上下文，不能保证每次正确。
