# 开发与编译

普通用户无需编译，请直接下载 Releases 中的 Windows `.exe` 安装包。

## 环境

- Windows 10 / 11，当前安装包面向 x64。
- Node.js 22 LTS 或更新的兼容 LTS。
- pnpm 9.15.0（根目录 `packageManager` 指定版本）。
- Git，用于获取源码。

## 获取与启动

```sh
git clone https://github.com/xhcao8-spec/seagrass-assistant.git
cd seagrass-assistant
pnpm install
pnpm dev
```

首次安装会下载 Electron，需能访问依赖下载源。不要通过关闭 TLS 证书校验来解决网络问题。

开发模式会启动桌面界面。平台登录、翻译和 AI 调用需要联网；在软件设置里填入自己的 DeepSeek Key，不要把真实 Key 写到源码或 `.env` 后提交。

## 检查与打包

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm package:win
```

测试使用模拟数据，不需要真实 Key，不会向真实联系人发送消息。安装包在 `release/`，官网静态文件在 `website/dist/`。Windows 打包通常需要在 Windows 环境运行。

## 目录说明

- `desktop/src/`：Vue 界面。
- `desktop/electron/main.cjs`：窗口、平台视图及 IPC。
- `desktop/electron/local-provider.cjs`：直接访问 DeepSeek、余额查询、临时失败重试。
- `desktop/electron/platform-preload.cjs`：WhatsApp 页面适配。
- `desktop/electron/assistant-vision.cjs`、`assistant-capture.cjs`：聊天图片上下文与边界校验。
- `website/`：静态官网，保留 Stitch 设计。
- `docs/`：中文教程和项目说明。

## 提交代码前

只提交源码、锁文件、文档与必要的公开素材。不要提交 `node_modules/`、`dist/`、`release/`、服务器备份、用户数据、API Key、Cookie 或含真实客户内容的截图。

修复平台适配时先补充模拟 DOM 的回归测试。AI 上下文必须区分“我”和“对方”，不得把引用消息或译文当成新的客户消息。插入建议时需确认当前聊天未切换，不得自动发送 AI 草稿。
