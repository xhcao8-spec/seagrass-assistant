# 静态官网部署与版本发布

## 官网部署

运行 `pnpm --dir website build`，将 `website/dist/` 的内容部署到静态站点，保留站点 HTTPS 证书和验证目录。桌面客户端直接访问聊天平台和 DeepSeek，官网只提供产品介绍、下载入口与使用教程。

网站字体和图片在本地构建产物中提供；图标使用从原 Material Symbols 提取的 SVG，不依赖外部图标字体。保持原有 Stitch 设计与品牌素材。

## 发布 Windows 版本

1. 更新根目录、桌面应用和发布配置中的版本。
2. 执行 `pnpm typecheck`、`pnpm test`、`pnpm build`。
3. 执行 `pnpm package:win`，检查 `release/` 下的安装包。
4. 将源码提交到 GitHub，创建对应版本的 Git tag 和 Release。
5. 上传 `.exe` 和 SHA256 校验值，在版本说明中介绍功能与使用方法。
6. 如提供蓝奏云下载，将同一安装包上传到固定文件夹，保持两个渠道版本一致。

蓝奏云文件夹：<https://wwamz.lanzouu.com/b01euscfwj>，提取码 `9ysu`。

GitHub：<https://github.com/xhcao8-spec/seagrass-assistant/releases>。

## 发布前检查

只提交源码、锁文件、文档和必要素材；不要提交运行数据、Key、Cookie、日志或服务器凭证。安装包应包含项目许可证和第三方声明。源码使用 GPL-3.0-only，发布修改版也应提供对应源码。
