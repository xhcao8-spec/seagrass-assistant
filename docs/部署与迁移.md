# 部署与迁移

## 目标架构

Windows 客户端直接访问聊天平台和 DeepSeek。宝塔仅部署静态官网，不承担登录、计费、翻译、AI、代理存储或客户同步。

此项目目录不包含原有 API 服务、管理后台、数据库、环境密钥、用户运行目录或旧安装包。旧工程保留在旁边的“海草跨境助手”目录，供核对和回退；不能整体上传到公开仓库。

## 官网

在项目根目录执行 `pnpm build`，部署 `website/dist/` 的**内容**到官网站点根目录，保留站点 TLS 配置。

Stitch 的布局、Logo 和配色保留；套餐区域改为同样卡片风格的使用说明。网站不请求 `/api/v1`，无需 PHP、Python 或数据库。

## 版本下载

固定文件夹：`https://wwamz.lanzouu.com/b01euscfwj`，提取码 `9ysu`。

安装包位于 `release/`。发布者自行登录蓝奏云，将已验证的安装包上传到同一文件夹。**本次代码构建不等于已经上传或公开发布。**

软件链接配置在 `desktop/electron/release.json`。官网入口在 `website/src/App.vue`。目前直接打开用户指定的固定蓝奏云链接。若以后启用官网中转页，可在下一版统一切换。

## 关闭旧服务器之前

1. 先用真实的自有 Key 验证余额、翻译和 AI 回复，并测试目标平台登录、客户标签和本地持久化。
2. 确认已有用户如何迁移，并备份旧数据库及服务配置。旧售卖版依赖后台，停掉后台后旧版将不能继续调用相关功能。
3. 确认静态官网和蓝奏云安装包已上线并可访问。
4. 再按明确服务名停止旧 API 和管理后台，移除该站点的 API 反向代理。
5. 数据库与历史备份应根据用户授权单独处理；不要把同一服务器上其他站点的数据一起删除。

目前没有执行宝塔服务停止、数据库删除或线上文件替换。

## 源码发布检查

先确认许可证，再发布。排除 `.migration-tools/`、`node_modules/`、`release/`、`dist/`、任何 `.env`、日志和运行数据。不要提交 API Key、平台 Cookie、真实聊天截图或服务器凭证。项目自己的 `.gitignore` 已包含常见排除项。
